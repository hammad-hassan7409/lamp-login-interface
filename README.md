# Lumina Login

Recreate the attached reference video as accurately as possible. Match the layout, spacing, proportions, animations, lighting, transitions and interactions as closely as possible instead of creating your own interpretation.
Create a premium single-page login experience with a dark luxury aesthetic.

This is NOT a traditional login page.

The page should feel cinematic, modern and interactive.

At the top center of the page, create a realistic hanging lamp suspended from a rope. The rope and lamp should be beautifully designed and slightly animated.

The background should be almost black with subtle gradients, soft ambient glow and premium lighting.

When the page loads, the lamp is OFF and the login card is almost hidden.

The user can click or pull the rope to turn the lamp ON.

When the lamp turns on:

• The light cone smoothly illuminates the center of the screen.

• The background becomes brighter around the light.

• The login card fades into view.

• The lamp swings naturally with realistic easing.

• The lighting should feel cinematic.

The login card must use glassmorphism.

Rounded corners.

Blurred transparent background.

Soft shadows.

Luxury typography.

Premium spacing.

The card contains:

• Username

• Password

• Show / Hide password

• Remember me

• Forgot password

DO NOT use a normal Login button.

Instead create a premium vertical swipe-down authentication control.

The swipe control should be centered below the password field.

It should display:

"Swipe Down to Enter"

The user must drag the circular handle downward.

If released before reaching 85%:

• The handle smoothly springs back to the top.

• No login occurs.

If dragged past 85%:

• The handle reaches the bottom.

• A green confirmation animation appears.

• The lamp becomes slightly brighter.

• The login card glows softly.

• Authentication succeeds.

Animations must be extremely smooth (60 FPS).

Add subtle floating animation to the login card.

Add premium hover effects.

Add animated background glow.

Everything must be responsive.

The design should feel like an Apple product mixed with Stripe design language.

Avoid generic UI components.

No Bootstrap.

No Tailwind look.

Everything should feel handcrafted and premium.

The page should look production-ready and visually impressive.
